# Сайты

- `client/` — сайт для клиентов и партнёров (основной домен, `CLIENT_DOMAIN`): заявка и расчёт, подпись договора, трекинг, личный кабинет клиента (вход по коду из SMS), кабинет партнёра. Входа для сотрудников здесь нет.
- `staff/` — сайт для сотрудников (поддомен, `STAFF_DOMAIN`): менеджер, водители, приёмщики терминалов. Закрыт от поисковиков.

Оба сайта раздаёт Caddy (`deploy/Caddyfile`). Он же пропускает к API только адреса, нужные своему сайту. Пока здесь заглушки, интерфейс переносится из `prototype/`.
