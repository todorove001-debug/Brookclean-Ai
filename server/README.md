# Brookclean — серверная часть

API и база данных для перевозки автомобилей автовозами из Владивостока, в том числе с перегрузкой на терминале Новосибирск. Правила взяты из кликабельного прототипа (`../prototype/index.html`).

Технологии: Node.js 22, TypeScript, Fastify, PostgreSQL 16.

## Что уже есть

- **Сотрудники.** Регистрация, вход по телефону и паролю, подтверждение менеджером. Роли: менеджер, водитель, партнёр, приёмщик терминала.
- **Клиент.** Расчёт по тарифной сетке (кэшбэк партнёра прибавляется к перевозке, страховка 0,3%). Заявка с паспортными данными и согласием на обработку ПД. Подпись договора кодом из SMS: хранятся хеш договора, время, телефон, IP. Трекинг по ссылке без персональных данных.
- **Рейсы.**
  - Прямой маршрут или через терминал, до 8 машин в рейсе.
  - Приёмщик терминала формирует рейс со своей площадки и ставит в него машины.
  - Водитель отмечает позицию.
- **Базы водителей и компаний.** Общая база у менеджера, своя база у терминала Новосибирск. Учётная запись водителя связывается с карточкой терминала по телефону.
- **Передача машины.** Этапы: приёмка → погрузка → приём на терминал → отгрузка с терминала → выгрузка.
  - Фото и видео по списку ракурсов. Файлы раскладываются по папкам: `Автомобили/2026/<№>_<авто>_<VIN>/<NN>_<этап>_<дата>_<город>/Фото|Видео|Подписи/`.
  - Дефекты на схеме с историей: кто добавил, уточнил, снял.
  - Подписи на экране. Сначала «Сдал», потом «Принял» — эта подпись закрывает этап. Любое изменение после подписи сбрасывает подписи. Менеджер снимает отметку и после подписей, с комментарием.
  - Отгрузка с терминала. Приёмщик — 2 фото на автовозе и «Сдал». Принимающий водитель — 10 фото, видео, дефекты и «Принял». Это делается в кабинете водителя или на экране приёмщика: записи идут на водителя.
- **История машины.** Фото, видео, подписи и дефекты прошлых передач открыты каждому участнику цепочки, посторонним — нет.
- **Журнал действий** (`audit_log`): кто, что и когда изменил.

## Запуск для разработки

```bash
cp .env.example .env            # проверить DATABASE_URL
npm install
npm run migrate                 # создать таблицы
SEED_PHONE=79001234567 SEED_PASSWORD=пароль123 npm run seed   # первый менеджер
npm run dev                     # http://localhost:3000/api/health
npm test                        # нужна база brookclean_test (TEST_DATABASE_URL)
```

Через Docker: `docker compose up --build` поднимает PostgreSQL и API на порту 3000. Миграции применяются при старте.

## Основные адреса API

Все адреса начинаются с `/api`. Сотрудники передают `Authorization: Bearer <token>` из `/auth/login`.

| Раздел | Адреса |
|---|---|
| Вход | `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `GET /me` |
| Сотрудники (менеджер) | `GET /users`, `POST /users/:id/status` |
| Клиент | `GET /tariffs`, `POST /quote`, `POST /orders`, `POST /orders/:no/sign/request`, `POST /orders/:no/sign/confirm`, `GET /track/:token` |
| Заказы (менеджер) | `GET /orders`, `GET /orders/:no`, `PATCH /orders/:no`, `POST /orders/:no/route` |
| Рейсы | `GET /trips`, `GET /trips/:id`, `POST /trips`, `PATCH /trips/:id`, `POST /trips/:id/status`, `POST /trips/:id/position`, `POST /trips/:id/cars`, `DELETE /trips/:id/cars/:no` |
| Водители и компании | `GET/POST /drivers`, `PATCH /drivers/:id`, `GET/POST /companies`, `PATCH /companies/:id` |
| Передача машины | `GET /orders/:no/stages`, `GET /orders/:no/stages/:stage`, `POST …/media` (multipart: `kind`, `slot`, файл), `POST/PATCH/DELETE …/marks`, `PATCH …/section`, `POST …/sign`, `GET /media/:id`, `GET /orders/:no/history`, `DELETE /orders/:no/marks/:id` (менеджер) |

## Следующие шаги

1. Хранилище Yandex Object Storage (S3) вместо папки на диске.
2. SMS-провайдер (SMSC или SMS.ru) и ограничение попыток входа.
3. Акт приёма-передачи и договор в PDF.
4. Взаиморасчёты с терминалом: депозит, перегрузка по прайсу, оплаты.
5. Рейсовый отчёт водителя: аванс, расходы, чеки.
6. Распознавание документов, чеков и повреждений (Yandex Vision / GigaChat).
7. Перевод прототипа на этот API (PWA для телефона).
