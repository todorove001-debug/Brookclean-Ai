# Справочники

- `Справочник_авто.xlsx` — модели, которые возили по таблицам рейсов (75 листов), стоянки и листу «АВТО» терминала: габариты, тип кузова, класс перегруза, история классов у терминала, расхождения.
- `car_models.json` — тот же справочник для программы: названия и варианты написания, номера кузова для выбора поколения.

Класс перегруза: **Малыш** — длина до 3,6 м включительно, строго по длине. Седан / Кросс / Джип — как ставил терминал, если по модели есть история, иначе по габаритам. Габариты ориентировочные, по данным производителей для поколения из таблиц — для спорных случаев сверяйте с экспортным сертификатом машины.
