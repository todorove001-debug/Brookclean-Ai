# Карта маршрутов разрешений

Подложка карты в прототипе собрана из данных Natural Earth в масштабе 1:10 млн (общественное достояние): суша, озёра, реки, границы стран и регионов России, дороги, населённые пункты с русскими названиями.

Как пересобрать:

1. Скачать в папку `ne/` файлы `ne_10m_roads`, `ne_10m_rivers_lake_centerlines`, `ne_10m_lakes`, `ne_10m_admin_1_states_provinces_lines`, `ne_10m_admin_0_boundary_lines_land`, `ne_10m_land`, `ne_10m_populated_places` (GeoJSON из репозитория nvkelso/natural-earth-vector).
2. Положить в `ne/corr.json` опорные пункты коридора `CORR` из прототипа.
3. `python3 route.py` прокладывает коридор Москва — Владивосток по дорожной сети. Где дорог в данных нет (часть трассы «Амур», новая М-12), линия идёт прямо между соседними опорными пунктами.
4. `python3 build.py` собирает `map2.json`, его содержимое встраивается в прототип как `PMAP`.
