# Brookclean-Ai

Сервис перевозки автомобилей автовозами из Владивостока по России, с перегрузкой на терминале Новосибирск.

- `prototype/` — кликабельный прототип: клиентская заявка, кабинеты, акт приёма-передачи.
- `server/` — серверная часть и база данных (Node.js, PostgreSQL). Как запустить — в `server/README.md`.
- `web/` — два сайта: `client/` для клиентов и партнёров (основной домен) и `staff/` для сотрудников (поддомен).
- `deploy/` — запуск на сервере Reg.ru с хранилищем S3: `deploy/README.md`.
