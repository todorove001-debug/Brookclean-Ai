# Бот согласования

Доступ — только пользователям из таблицы `users` по числовому Telegram ID (первые владельцы и администраторы создаются из `BOOTSTRAP_*_TELEGRAM_IDS`, остальные — через API или `factory create-user`). Бот отвечает только в личных сообщениях.

## Черновик

Для каждого материала, прошедшего проверки, бот присылает:
1. медиа (изображение или видео; если видео больше лимита Bot API — превью);
2. текст поста ровно так, как он будет опубликован;
3. карточку: тема, время, цель, критерий успеха, результат проверок (⛔ блокирующие, 🔎 для вашей проверки, ⚠️ замечания), источники с датами, учтённые правки — и кнопки.

| Кнопка | Что происходит |
|---|---|
| ✅ Одобрить | Есть только если обязательные проверки пройдены. Фиксирует одобрение версии и её контрольной суммы, назначает ближайшее разрешённое время. Если были пункты 🔎, одобрение означает, что вы их проверили. |
| ✏️ Правки | Бот попросит текст правок; появится новая версия. |
| 🔁 Переписать текст | Новый вариант текста с теми же фактами. |
| 🎬 Пересобрать видео | Параметры текстом: `формат 1:1`, `длительность 30`, `без ии`, `без субтитров`, `без логотипа`, `обрезать`, `высокое качество`, `без концовки`; остальное — пожелания к стилю ИИ-сцен. Текст поста сохраняется. |
| 🕒 Перенести | Свободные слоты кнопками или своё время (`25.11 14:30`, `завтра 10:00`, `18:30`) — по часовому поясу канала. |
| ❌ Отклонить | Материал не будет опубликован. |

Кнопки привязаны к версии. После правок старые кнопки перестают работать — откройте новый черновик.

## Команды

| Команда | Назначение |
|---|---|
| `/drafts` | черновики на согласовании |
| `/item <id>` | открыть материал (первые 8 символов ID) |
| `/plan [7\|30]` | контент-план |
| `/newplan 7\|30` | составить план |
| `/queue` | очередь публикаций и состояние паузы |
| `/status <id>` | статус, задания видео, ошибки, message ID |
| `/costs` | расходы за день и месяц, лимиты, разбивка |
| `/errors` | ошибки за 7 дней |
| `/pause [причина]`, `/resume` | пауза и возобновление очереди публикаций |
| `/idea <тема>` | добавить идею |
| `/story <факты>` | история перевозки по вашим фактам |

## Публикация запрещена, если

- материал не одобрен или изменён после одобрения (контрольная сумма не совпадает);
- не пройдены обязательные проверки;
- не найден или изменён медиафайл;
- материал отменён или очередь на паузе;
- одобривший пользователь отключён или лишён права одобрять.

О любой остановке владельцу приходит уведомление.
