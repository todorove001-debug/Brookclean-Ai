# Инструкция по боту Brookclean Content Factory

Бот присылает вам черновики постов для канала @Brookcleantrucks. Ничего не публикуется без вашего одобрения. Команды бота написаны по-английски, рядом — что они делают.

## Как это работает

1. Каждое утро система составляет план постов на неделю вперёд.
2. За 2 дня до публикации готовит пост: текст, обложку или видео.
3. Присылает вам черновик в бот.
4. Вы нажимаете **✅ Одобрить** — пост встаёт в очередь и выходит в назначенное время.

## Команды (Commands)

Команду можно набрать или выбрать в меню «/» рядом с полем ввода.

| Команда | Английское значение | Что делает |
|---|---|---|
| `/help` | help — помощь | Список команд |
| `/drafts` | drafts — черновики | Посты, которые ждут вашего решения. Нажмите на пост, чтобы открыть |
| `/item 1a2b3c4d` | item — материал | Открыть конкретный пост по номеру (первые 8 символов из `/plan` или `/queue`) |
| `/plan` | plan — план | План на 7 дней. `/plan 30` — на 30 дней |
| `/newplan 7` | new plan — новый план | Составить план заново: `/newplan 7` или `/newplan 30` |
| `/queue` | queue — очередь | Одобренные посты и время их выхода |
| `/status 1a2b3c4d` | status — состояние | Где сейчас пост: пишется, монтируется, ждёт, опубликован; ошибки |
| `/costs` | costs — расходы | Сколько потрачено на ИИ сегодня и за месяц (лимит 250 $) |
| `/errors` | errors — ошибки | Что пошло не так за неделю |
| `/pause` | pause — пауза | Остановить публикации (черновики продолжат приходить). Можно указать причину: `/pause отпуск` |
| `/resume` | resume — продолжить | Возобновить публикации |
| `/idea Как зимой готовить машину к перевозке` | idea — идея | Добавить свою тему для поста |
| `/story Привезли Toyota Prius в Тюмень, клиент…` | story — история | История перевозки по вашим фактам. Бот ничего не придумывает сверх написанного |

## Кнопки под черновиком (Buttons)

| Кнопка | Английский смысл | Что происходит |
|---|---|---|
| ✅ **Одобрить** | Approve | Пост одобрен и встаёт в очередь на ближайшее свободное время |
| ✏️ **Правки** | Edit / Request changes | Бот спросит, что изменить. Напишите одним сообщением, например: «Убери второй абзац, добавь про зимнюю погрузку» |
| 🔁 **Переписать текст** | Rewrite | Новый вариант текста на ту же тему |
| 🎬 **Пересобрать видео** | Re-render video | Бот спросит параметры (см. ниже) |
| 🕒 **Перенести** | Reschedule | Выберите свободное время из списка или «Ввести время вручную» (Custom time) |
| ❌ **Отклонить** | Reject | Пост не будет опубликован |

Кнопки относятся к конкретной версии поста. Если вы попросили правки, придёт новая версия, а кнопки под старой перестанут работать.

### Время при переносе

Пишите по московскому времени:
- `25.11 14:30` — конкретная дата;
- `завтра 10:00`;
- `18:30` — сегодня, а если время уже прошло — завтра.

Посты выходят с 08:00 до 22:00, не чаще одного раза в полтора часа.

### Параметры видео (Video options)

После кнопки 🎬 напишите параметры в любом порядке:

| Что написать | Английский смысл | Что изменится |
|---|---|---|
| `формат 9:16` / `16:9` / `1:1` | aspect ratio — пропорции | Вертикальное, горизонтальное или квадратное видео |
| `длительность 30` | duration — длительность | Длина ролика в секундах (5–180) |
| `без субтитров` | no subtitles | Убрать субтитры |
| `без логотипа` | no logo | Убрать логотип |
| `обрезать` | crop — кадрирование | Обрезать кадр вместо размытого фона по краям |
| `без концовки` | no outro | Убрать финальную заставку с контактами |
| любой другой текст | style — пожелания | Например: «больше кадров погрузки, спокойнее» |

Пример: `формат 1:1, длительность 20, без субтитров, больше кадров с трассы`

## Значки в карточке черновика (QA)

Под каждым черновиком — результат проверки качества:

| Значок | Английский смысл | Значение |
|---|---|---|
| ✅ проверки пройдены | passed | Всё в порядке |
| 🟡 есть пункты для проверки | needs review | Система сомневается в каком-то утверждении — прочитайте отмеченное. Нажимая «Одобрить», вы подтверждаете, что проверили |
| ⛔ | blocking — блокирует | Серьёзная проблема, например в тексте цена или обещание без подтверждения. Кнопки «Одобрить» не будет — нажмите «Правки» или «Переписать текст» |
| 🔎 | manual check — проверьте сами | Пункт для вашей проверки |
| ⚠️ | warning — замечание | Можно публиковать, но стоит обратить внимание |

## Загрузка съёмок (Upload)

Просто отправьте боту видео или фото **с подписью**, что снято:
- «погрузка Prius на верхний ярус»;
- «крепление колёс»;
- «автовоз в пути под Читой»;
- «выдача машины клиенту в Новосибирске».

Бот ответит «✅ сохранено в библиотеку». Монтаж сам подберёт кадры к сценарию.

- Фото для обложек отправляйте **файлом** (скрепка → Файл): так Telegram их не сжимает.
- Файлы **больше 20 МБ** бот принять не может — это ограничение Telegram. Загружайте их через веб-панель, раздел «Загрузка».

## Сообщения от бота (Notifications)

Бот сам пишет вам, когда:
- ✅ пост опубликован;
- ❗ пост не удалось подготовить или опубликовать — с причиной;
- ❓ публикация не подтверждена — проверьте канал вручную;
- ⚠️ расходы дошли до 50%, 80%, 95% лимита;
- ⛔ лимит исчерпан — платные задачи остановлены до следующего дня или месяца;
- 🗓 составлен новый план;
- 📊 по понедельникам — отчёт за неделю.

## Меню команд в Telegram

Чтобы команды появились в меню «/», отправьте @BotFather команду `/setcommands`, выберите своего бота и вставьте:

```
drafts - Черновики на согласование
plan - План публикаций (7 или 30 дней)
queue - Очередь публикаций
status - Состояние поста
item - Открыть пост
newplan - Составить план
idea - Добавить тему
story - История перевозки
costs - Расходы на ИИ
errors - Ошибки за неделю
pause - Остановить публикации
resume - Возобновить публикации
help - Помощь
```

## Частые вопросы

**Черновики не приходят.** Сначала напишите боту `/start`. Если не помогло — проверьте `/errors`.

**Пост одобрен, но не вышел.** Посмотрите `/queue`: возможно, время ещё не наступило или включена пауза (`/resume`).

**Бот пишет «Нет доступа».** Бот отвечает только пользователям, чей Telegram ID внесён в систему. Добавить сотрудника можно через администратора системы.

**Можно ли изменить уже одобренный пост?** Да: нажмите ✏️ «Правки» под ним. Одобрение снимется, придёт новая версия — её нужно одобрить заново.
